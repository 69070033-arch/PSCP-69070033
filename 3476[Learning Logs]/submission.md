# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์นี้เกี่ยวกับแมวกับจิ้งจอกในฝูง แต่ละตัวมีหมายเลขติดไว้ หน้าตาของหมายเลขจะบอกว่าเป็นแมวหรือจิ้งจอก อย่าง Cat01 ก็คือแมวตัวที่หนึ่ง Fox01 คือจิ้งจอกตัวที่หนึ่ง

ส่วนที่ยากที่สุดคือข้อมูลที่ให้มามันไม่ครบ โจทย์บอกว่าปกติจะมีแมวชื่อ Garfield ที่ Cat01 กับจิ้งจอกชื่อ Fubuki ที่ Fox01 อยู่เสมอ ถ้าข้อมูลที่ได้มาไม่มีเลข 01 ของชนิดไหน แปลว่าตัวนั้นคือชื่อกลางที่ต้องเติมกลับเข้าไปเอง

อีกจุดที่ต้องระวังคือชื่อ Garfield กับ Fubuki อาจไปโผล่ในข้อมูลแล้วก็ได้ แม้จะถูกใช้เป็นจิ้งจอกไม่ใช่แมว ถ้าชื่อนั้นถูกใช้ไปแล้วก็ไม่ต้องเติมซ้ำ

ส่วนผลลัพธ์ บรรทัดแรกพิมพ์จำนวนแมว บรรทัดที่สองพิมพ์จำนวนจิ้งจอก แต่ละบรรทัดใช้รูปแบบ ชื่อ : หมายเลข แล้วเรียงตามหมายเลข โดยเอาแมวขึ้นก่อนจิ้งจอก

- Input: บรรทัดแรกเป็นจำนวนบรรทัดทั้งหมด แต่ละบรรทัดเป็น dict แบบหนึ่งคู่ เขียนเป็น {"ชื่อ" : "หมายเลข"} ถ้าไม่ได้ตั้งชื่อ key จะเป็นค่าว่าง
- Output: จำนวนแมว 1 บรรทัด จำนวนจิ้งจอก 1 บรรทัด แล้วรายชื่อทั้งหมดเรียงตามหมายเลข
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
ตอนแรกคิดแค่ว่าอ่านเข้ามาแล้วเอาไปแยก list สองอัน อันนึงแมวอันนึงจิ้งจอก แล้วนับความยาวมาพิมพ์ คิดว่าจบแล้ว

แต่ตอนลองเขียนจริงติดสองเรื่อง อย่างแรกที่เรียงตามหมายเลข ผมใช้ sort ของ list ธรรมดา ซึ่งมันเทียบเป็นข้อความ ผลคือถ้ามี Cat100 มันจะไปก่อน Cat99 ซึ่งผิด อย่างที่สองคือตอนแรกผมคิดว่า "ถ้าชื่อไม่ได้ตั้งก็ใส่ชื่อกลางแทนเลย" ซึ่งพอลองกับข้อมูลจริงแล้วผิด เพราะมันไปแขวะชื่อกลางไว้กับตัวที่เลขไม่ใช่ 01
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
อ่านแต่ละบรรทัดแล้วตัดวงเล็บออก แล้วแยกด้วยเครื่องหมาย colon เอาส่วนซ้ายเป็นชื่อ ส่วนขวาเป็นหมายเลข เก็บลง dict โดยใช้หมายเลขเป็น key แล้วจำชื่อที่เจอทั้งหมดไว้ใน set

พออ่านครบก็เอามาแยกอีกทีเป็น list ของแมวกับของจิ้งจอก โดยตัดเลขท้ายหมายเลขมาแปลงเป็น int เก็บไว้หน้าสุดของ tuple เพื่อให้ sort แล้วเรียงเป็นตัวเลขจริง

จากนั้นเช็คว่าชนิดไหนยังไม่มีเลข 1 อยู่ ถ้าไม่มีก็เติมชื่อกลางของชนิดนั้นเข้าไป แต่ต้องเช็คด้วยว่าชื่อกลางนั้นยังไม่ถูกใช้ในข้อมูล ไม่งั้นจะซ้ำ พอครบแล้วก็พิมพ์จำนวนของแต่ละชนิดตามด้วยรายชื่อ
```

## 5. การทดสอบของฉัน

เขียน test cases อย่างน้อย 3 กรณีที่ลองเองหรือออกแบบเอง

พยายามเลือก test cases ที่แตกต่างกัน

แต่ละ test case ให้อธิบายว่าทำไมเลือกกรณีนั้น

ถ้า input หรือ output มีหลายบรรทัด ให้เขียนไว้ใน text blocks

### Test Case 1

ทำไมเลือก case นี้:

```text
เคสนี้ข้อมูลครบจำนวนเลข 01 ของทั้งสองชนิดเลย ผลลัพธ์เลยต้องมีตัวที่โค้ดเติมเข้าไปเองหนึ่งตัวต่อชนิด ใช้ดูว่าตัวที่เติมถูกนับรวมในจำนวนด้วย
```

```text
5
{"Chi" : "Cat06"}
{"Tom" : "Cat05"}
{"Shiro" : "Fox02"}
{"Senko" : "Fox10"}
{"Chocola" : "Cat03"}
```

```text
Fox : 3
Garfield : Cat01
Chocola : Cat03
Tom : Cat05
Chi : Cat06
Fubuki : Fox01
Shiro : Fox02
```

## 6. การใช้ AI

ใช้ AI กับโจทย์นี้หรือไม่

```text
No
```

ถ้าใช้ AI ต้องทำไฟล์นี้ด้วย:

```text
ai_reflection.md
```

ถ้าถามเฉพาะเพื่อน TA หรือผู้สอน และไม่ได้ใช้ AI ไม่ต้องทำ `ai_reflection.md`

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text
No
```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน

ใครช่วยคุณ

```text
ไม่มี
```

เขาช่วยอะไร

```text
ไม่มี
```

คุณยังทำอะไรด้วยตนเอง

```text
ไม่มี
```

คุณคัดลอก code จากคนอื่นหรือไม่

```text
No
```
